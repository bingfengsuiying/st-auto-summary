# 剧情自动总结 · Auto Summary

一个 SillyTavern 扩展：每 50 条聊天做一次小总结，每 100 条做一次大总结，并把总结写进世界书，作为常驻设定辅助后续生成。

兼容 **SillyTavern 1.13.x ~ 1.18.x**，桌面与手机浏览器都能用。

> A SillyTavern extension that periodically summarizes the chat (small every 50 messages, big every 100) and stores the summaries as always-on world info entries.

---

## 它怎么工作

- 每 **50 条**消息：生成一段“剧情小总结”，覆盖这 50 条里的关键事件、关系变化、承诺、伏笔；
- 每 **100 条**消息：生成一份“剧情大总结”，会把**上一份大总结**一起合并，形成滚动的主线梗概；
- 到了 100 的整数倍时只跑大总结（大总结已经覆盖这一区间，不再重复跑小总结）；
- 所有总结写入**世界书**，以“常驻条目”注入提示词，不修改、不删除任何聊天记录；
- 世界书里只保留最近 N 条小总结（默认 3）和 1 条大总结，旧的自动清理，避免 token 越滚越多。

总结条目默认插在聊天记录末尾的深度位置（小总结 depth 4、大总结 depth 8），也可以改成“角色定义前”。

## 总结写到哪本书

按下面的顺序决定：

1. 设置里填了「指定世界书」→ 写进那本（**不会**自动激活，需要你自己在酒馆里启用）；
2. 当前聊天已经绑定世界书（聊天世界书 / Chat Lore）→ 直接写进去；
3. 都没有 → 自动创建一本 `自动总结 - 角色名 - xxxx`，并绑定到当前聊天（只影响这个聊天）。

自动模式需要聊天已经保存过（有聊天文件），否则会提示「当前聊天还没有保存」。

## 安装

### 酒馆内安装（推荐）

扩展 → **Install extension** → 填仓库地址：

```
https://github.com/bingfengsuiying/st-auto-summary
```

刷新页面即可。

### 手动安装

把整个 `st-auto-summary` 文件夹放到：

```
SillyTavern/public/scripts/extensions/third-party/st-auto-summary/
```

确认结构是 `third-party/st-auto-summary/manifest.json`，不要多套一层同名文件夹。
手机用文件管理器 / ZArchiver 复制，Termux 装的一般在 `~/SillyTavern/...`，然后刷新页面。

## 使用

打开「扩展」面板里的「剧情自动总结」：

1. 勾选 **自动生成剧情总结并写入世界书**；
2. 小总结间隔默认 50、大总结间隔默认 100，可按需改；
3. 「世界书里保留最近 N 条小总结」默认 3；
4. 注入位置默认「聊天记录末尾」，也可以选「角色定义前」；
5. 点 **立即小总结 / 立即大总结** 可以马上补一次，不用等里程碑。

手机端面板会自动排在扩展设置区最前面；点输入框旁的**魔杖菜单**还有两个快捷入口：
`剧情总结：开/关`、`立即小总结`。

状态行会显示当前进度和世界书情况，例如：

```
共 137 条 · 下次小总结在 150 条（还差 13） · 下次大总结在 200 条（还差 63）
世界书：《自动总结 - 小蝶 - a1b2》（小 2 / 大 1）
上次：小总结 · 20:15
```

## 生成与成本

- 使用当前接口的 `generateRaw` 静默生成，不会在聊天里留下消息；
- 每次最多把 `maxInputChars`（默认 8000 字符）的聊天内容喂给模型，超长消息会逐条截断，优先保留较新的内容；
- 输出限制：小总结 500 字、大总结 1000 字（提示词里要求 250 / 500 字以内）；
- 失败会提示原因，并进入 60 秒冷却，避免每来一条消息就重试一次。

## 世界书条目长什么样

- 注释：`[自动总结][小] 第 51-100 条` / `[自动总结][大] 第 1-200 条`
- 常驻（constant）、关键词为空，所以一定会参与提示词；
- 关闭递归（excludeRecursion / preventRecursion），避免总结里的名字触发别的条目；
- `automationId` 为 `st-auto-summary`，方便识别；
- 同一范围重复总结会更新原条目，不会堆重复。

「清理总结条目」按钮会删掉当前书里所有本插件生成的条目，并重置本聊天的进度。

## 适用场景与注意

- 适合长聊天：用少量 token 换“前情记忆”，比一路带全文便宜；
- 小总结是细节、大总结是主线，两者都会常驻，注意别把保留条数设太大；
- 如果你手动编辑总结条目，插件下次可能覆盖同一范围的条目；
- 删除聊天不会自动删除世界书，确认不需要后可以手动删书。

## 排障

**提示 Authorization Required / API returned an error**
接口密钥或模型配置有问题，先在酒馆里正常发一条消息确认能生成。

**点了没反应 / 提示“当前聊天还没有保存”**
新聊天需要先有一条消息并落盘；或者先在设置里指定一本世界书。

**世界书里没有总结**
打开世界书面板确认书是否存在、条目是否被禁用；指定世界书模式下要确认这本书已经激活。

**手机上没有面板**
检查路径层级，强制刷新页面；确认「管理扩展」里扩展是启用状态。
